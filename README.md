# C# console app

A starter console application targeting .NET 10 LTS.

## Cloud environment

Activate the installed SDK in each new shell:

```bash
source /workspace/.setup/dotnet/env.sh
cd /workspace/go-workout
```

## Build and run

```bash
dotnet restore Workout.slnx
dotnet build Workout.slnx --no-restore
dotnet run --project src/Workout.Console --no-build
```

The app prints `Hello, World!`. Edit `src/Workout.Console/Program.cs` to begin.

Outside this cloud environment, install the .NET SDK specified in `global.json`
before running the build commands. Building and running the starter console app
requires no database. Using the audit module requires MySQL 8.0+.

## User audit log CRUD module

`src/Workout.AuditLogs` is a reusable class library using MySqlConnector.
Apply `database/user_audit_log.sql` to your database first. It preserves your
schema and adds `IF NOT EXISTS`; it does not migrate an existing table.

Supply your connection string through `AUDIT_DB_CONNECTION` using your secret
manager or shell environment. Never commit credentials. The database account
needs SELECT, INSERT, UPDATE, and DELETE permissions on `user_audit_log`.
Use a separate deployment account to create the table.

The console project already references the module. Example code for `Program.cs`:

```csharp
using System.Text.Json;
using Workout.AuditLogs;

var connectionString = Environment.GetEnvironmentVariable("AUDIT_DB_CONNECTION")
    ?? throw new InvalidOperationException("Set AUDIT_DB_CONNECTION.");
var repository = new UserAuditLogRepository(connectionString);

var data = new UserAuditLogData
{
    UserId = "user-123",
    ActionType = AuditActionType.ADD,
    NewExpiry = new DateOnly(2027, 10, 27),
    NewData = JsonSerializer.SerializeToElement(new { plan = "premium" }),
    PerformedBy = "admin"
};

long id = await repository.CreateAsync(data);
UserAuditLog? record = await repository.GetByIdAsync(id);
IReadOnlyList<UserAuditLog> history = await repository.ListAsync("user-123", limit: 50, offset: 0);

bool updated = await repository.UpdateAsync(id, data with
{
    ActionType = AuditActionType.RENEW,
    OldExpiry = data.NewExpiry,
    NewExpiry = new DateOnly(2028, 10, 27)
});
bool deleted = await repository.DeleteAsync(id);
```

All methods accept a `CancellationToken`. IDs and timestamps are generated by
MySQL. `UpdateAsync` replaces the editable fields and preserves `CreatedAt`;
it returns true for unchanged existing records. Missing IDs return null on reads
and false on updates or deletes. Lists return newest records first with a stable
ID tie-breaker; omit the user ID to list all records. Page size is 1–1000.
SQL values are parameterized, and length, enum, JSON, and date inputs are validated.
Connection, cancellation, and database errors propagate to the caller.

`DateOnly?` maps to SQL DATE. `JsonElement?` maps to JSON: C# null represents SQL
NULL, while a JsonElement containing JSON null remains JSON null. Returned JSON
values remain valid independently of the database reader. MySQL DATETIME has no
timezone, so `CreatedAt` is returned with `DateTimeKind.Unspecified`; use a consistent
database session timezone if interpreting timestamps as UTC.

The module edits audit records only; it does not modify a users table or
automatically log other application operations. `AuditActionType.DELETE` describes
a logged action; `DeleteAsync` permanently removes an audit record. Expose update
and delete only to callers authorized to change audit history.

## Tests

With Docker running, use a disposable MySQL 8.4 database:

```bash
bash scripts/test-mysql.sh
```

The script waits for database readiness, runs the seven tests, and removes its
container on exit. It binds a random port on loopback and uses no production data.

Alternatively, set `AUDIT_DB_CONNECTION` to a disposable MySQL 8.0+ test database
and run `dotnet test Workout.slnx`. Tests create the audit table if missing and
insert/delete their own rows. They require CREATE permission in addition to CRUD.
Without a connection string the integration tests fail with a configuration message.
